# GCL_Map

ZWCAD / AutoCAD 배경지도 플러그인 — **배포용 저장소**입니다.

이 저장소에는 **설치 파일만** 올라갑니다. 소스 코드는 사내 저장소에서 관리합니다.

## 다운로드

최신 설치 파일은 [Releases](../../releases/latest) 에서 받으세요.

## 버전 표기

`GCLMap.yymm.aa.bb`

| 자리 | 의미 |
|---|---|
| yymm | 빌드한 년월 (2610 = 2026년 10월) |
| aa | 그 달의 기능 추가 횟수 |
| bb | 그 달의 개선·버그 수정 횟수 |
